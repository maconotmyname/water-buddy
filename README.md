# 水滴搭子 WaterBuddy

一只常驻 Windows 桌面的地下城像素风喝水宠物。水滴搭子会根据水杯容量把每日目标调整为整杯倍数，在设定的饮水时段内平均安排提醒，并自动避开午休等免打扰时间。

它既可以作为完整的喝水计划面板使用，也可以缩成始终置顶的透明桌宠。悬浮或单击宠物即可查看今天喝了几杯、还差几杯，以及当前时段是否已经喝水。

## 下载安装

前往 [Releases 下载页](../../releases/latest)，根据需要选择：

- `WaterBuddy-Setup-1.0.1-x64.exe`：安装版，支持选择安装目录、桌面快捷方式和开始菜单快捷方式。
- `WaterBuddy-Portable-1.0.1-x64.exe`：免安装版，下载后直接运行。

目前提供 Windows x64 构建。发布包尚未配置商业代码签名证书，首次运行时 Windows SmartScreen 可能显示“未知发布者”。这是签名状态提示，不影响程序功能。

## 功能亮点

- Windows 系统通知和界面内提醒，推送不会改变窗口的显示状态、位置或模式
- 系统托盘常驻，关闭窗口后继续运行
- 透明桌宠模式，支持 `70%–140%` 大小调节、拖动和始终置顶
- 悬浮能量格显示已喝杯数、剩余杯数和当前时段状态
- 单杯容量支持 `100–1000 mL` 直接输入和 `±50 mL` 步进调节
- 每日目标自动调整为整杯倍数
- 在喝水时段内平均分配提醒，并完全跳过午休免打扰区间
- 工作版与假日版独立计划，周末自动切换，也可当天手动覆盖
- 饮水记录、撤销和跨日自动重置
- 今日时间线与月历视图，按比例显示每日完成圆环
- 最近两年的饮水历史保存在本地
- 随机补水小贴士和可选开机自动启动

## 使用桌宠

点击标题栏右上角的“桌宠模式”图标，窗口会缩成透明水滴并从任务栏隐藏。

- 拖动宠物：移动到桌面任意位置
- 悬浮宠物：临时显示今日饮水状态
- 单击宠物：固定或收起状态面板
- 双击宠物：恢复完整窗口
- 点击状态面板中的水杯按钮：直接记录一杯水
- 点击状态面板右侧的 × 按钮：隐藏到系统托盘，定时提醒继续运行

窗口右上角的关闭按钮只会隐藏应用。需要完全退出时，请右键系统托盘中的水滴图标并选择“退出”。

隐藏到托盘后，喝水提醒仍通过系统通知送达，桌宠不会自动弹出。只有主动点击通知或操作托盘时才会打开窗口。

## 数据与隐私

水滴搭子无需账号，也不会上传饮水记录。设置、当日进度和月历历史都保存在 Windows 当前用户的 Electron 应用数据目录中，历史自动保留最近 730 天。

## 本地开发

需要 Node.js 18 或更高版本。

```powershell
git clone https://github.com/maconotmyname/water-buddy.git
cd water-buddy
npm install
npm start
```

运行测试和生成 Windows 安装包：

```powershell
npm test
npm run dist
```

打包结果会输出到 `release` 目录，包括安装版和免安装版。
